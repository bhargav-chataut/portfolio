# Bhargav Chataut — Portfolio

Modern portfolio built with React, TypeScript, Vite, Framer Motion, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy

This repository includes a GitHub Pages workflow at `.github/workflows/deploy.yml`.
Enable **Settings → Pages → Source: GitHub Actions** once, then pushes to `main` will deploy automatically.
